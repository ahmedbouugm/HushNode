# HushNode

HushNode enables real-time data processing and auto-scaling capabilities on cloud-based architectures, utilizing load balancers for optimized processor utilization.

With HushNode, you get a lightweight tool that stays out of your way.

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/HushNode.git`
2. `cd HushNode`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
